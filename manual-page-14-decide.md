<h1 align="center">Decide</h1>

Decide evaluates a dictionary, with a possible default value.

First-match generalized switch/match over n×2k train tables: n×2 returns 1×1 (a scalar); n×4 returns 1×2; generally n×2k returns 1×k. An explicit trailing C is the default — the unmatched-result filler, not an else branch. If C is missing, C is assumed Nil: an unmatched value returns Nil without logging an error. Canonical form: `R ← X ¿ ¡ A B C`.
