<h1 align="center">Deal</h1>

Deal makes a random integer from 0 up to but less than specified.

Like Count, but random. Given a scalar n, yields a random integer r with 0 ≤ r < n. Given an array, fills the entire back rank with limited values.

Examples:

- #0: `? 6` ⍠ a random integer from 0 to 5 ⋄
