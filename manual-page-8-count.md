<h1 align="center">Count</h1>

Count fills an array matching a given shape, counting along the back rank.

Given a scalar, behaves as normal. Given an array shape, fills the array with the next dimension limited by the scalar from the back rank: `⍳ 2 3` yields rows of `0 1 2` (origin 0; the last axis counts, outer axes replicate).

Examples:

- #0: ⍳ 2 3 ⍠ rows of 0 1 2 ⋄
